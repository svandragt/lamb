- Behind a TLS proxy, Lamb now marks its cookies `Secure` on requests to the host of an `https://` site URL, instead of only when the request itself arrived over HTTPS ([#995](https://github.com/svandragt/lamb/issues/995)). Saving an `https://` site URL for the host you are using over plain HTTP now shows a warning, because the browser drops `Secure` cookies there and you could not log in again.
