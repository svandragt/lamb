- Behind a TLS proxy, Lamb now marks its cookies `Secure` on requests to the host of an `https://` site URL, instead of only when the request itself arrived over HTTPS ([#995](https://github.com/svandragt/lamb/issues/995)). Saving the settings form now shows a warning when it changes the site URL Lamb uses from `http://` (or none) to `https://` for the host you are on and the request did not arrive over TLS, because over `http://` the browser drops `Secure` cookies and you could not log in again. Re-saving an `https://` site URL, or saving while `LAMB_SITE_URL` is set, does not warn.
