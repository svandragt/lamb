- The Micropub media endpoint accepts an access token sent as `access_token` in the form body when there is no `Authorization` header, and refuses a request that sends the token in both places with `400 invalid_request` ([#993](https://github.com/svandragt/lamb/issues/993)).
- `/micropub` and the media endpoint now choose the access token by one rule: they trim it, treat a blank token or a `Bearer` header with no token as missing (a `401`), read the `Authorization` header name in any letter case, and no longer take the tail of a header such as `Bearerxyz` as a token ([#993](https://github.com/svandragt/lamb/issues/993)).
